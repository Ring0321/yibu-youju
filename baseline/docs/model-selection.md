优先使用控制台显示的业务空间专属 Base URL；示例保留官方支持的 DashScope 兼容地址。密钥、域名和模型必须对应同一地域，不在不同地域之间静默回退。模型发送范围、存储和保留政策要在真实素材接入前告知用户。[地域及域名说明](https://help.aliyun.com/zh/model-studio/beijing-access-information)、[创建和配置密钥](https://help.aliyun.com/zh/model-studio/get-api-key)

## 3. 调用协议

1. 首轮用非思考模式验证结构提取，候选使用严格 JSON Schema；工具选择使用 Function Calling，参数仍在后端校验。先分别测试两种接口能力，不假定任意参数组合都可共用。
2. 模型输出只有候选和提案，不能直接写 `verified`、质保结论、可信等级或完成状态；所有 ID 必须存在且在授权范围。
3. 禁用联网搜索和任意 URL/命令工具，仅开放项目定义的只读工具；资料中的指令视为待分析内容。
4. 正常一个 run 最多两次模型调用，最多再增加一次格式修复，**所有网络尝试合计不超过三次**。SDK 内置重试必须关闭或接入同一预算；重试、队列重放和切模型不能清零。
5. 单次请求最多 45 秒，并受剩余执行期限约束；候选输出上限先设 2048 tokens，截断属于失败，不靠截断 JSON 继续执行业务。
6. 模型拒绝、限流、认证失败、格式错误或不可识别均是合法可见状态。没有密钥时返回未配置，不能使用录制答案伪装成功。

JSON Schema 只约束输出结构，不证明来源有效、观察正确或业务授权；必须继续做应用层校验。[结构化输出](https://help.aliyun.com/zh/model-studio/qwen-structured-output)、[工具调用](https://help.aliyun.com/zh/model-studio/qwen-function-calling)

## 4. 成本与预算口径

核查时主模型北京地域、输入不超过 256k 档，公开原价为输入 2 元/百万 tokens、输出 8 元/百万 tokens；以控制台实际授权和账单为准，不把文档限流额度当成当前账号保证。[价格原文](https://help.aliyun.com/zh/model-studio/qwen3-7-plus)

例如一次请求实际计费输入 8000 tokens、输出 1000 tokens，按该档估算为 `8000/1000000*2 + 1000/1000000*8 = 0.024 元`。若两次请求规模相同则约 0.048 元。这不是每个售后会话的固定价格；图片计费输入、重复上下文、重试、嵌入、思考和多轮操作均须计入实际用量。

日/月预算由用户批准后配置；未批准前只完成无调用的配置和契约测试，不自动充值、不购买套餐、不进行批量真实调用。首轮建议只做少量冒烟，再用真实 token 量估计每单成本。
