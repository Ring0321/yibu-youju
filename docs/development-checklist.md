- 开发子项：12/205 完成。
- 工作包：1/41 完成（T01）。
- 产品验收：0/28 通过。
- 发布门禁：尚未通过 G0-S、G0-P 或 L1/L2 整体验收。
- 计划/研究文件已存在；既有 20 项合成机制测试不计作本版产品验收。

**勾销规则：** 未开始、进行中、阻断、测试失败均保留 `- [ ]`；真实验证完成后改成 `- [x] ~~Txx.yy 任务标题~~`。在该项下记录日期、执行者、测试范围、证据路径与剩余限制。代码写完但未运行不得划掉；跳过或不适用不算完成。

每个子项提供操作、产物和可观察验收。所有未勾选项默认“未验收”；只有补充的状态记录可写进行中/阻断。一个工作包只有全部子项完成、其必要资源和验收满足后才算完成。共享基础验证可以被多项引用，但同一实际工时不重复计入。

实际人时须由执行者记录，未计时写“未单独计时”，不得按计划数字回填。A/B/C 只是后端工程、模型与规则、前端与验证的职责归集，不是已确认成员，也不等于实际个人负荷。

出现回归时取消勾选与删除线，保留旧完成证据并追加重开原因。不得删掉失败记录，让历史看起来一直成功。模型真实调用、模拟故障、合成逻辑、实机试验分栏记录。
